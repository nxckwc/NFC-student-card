# Site — NFC Student Attendance Dashboard

Dashboard for the NFC student attendance system.

## Tech Stack

- Next.js, React, TypeScript
- Tailwind CSS

## Packages

- Framer Motion
- Lucide React
- Axios, TanStack Query, Zustand

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
